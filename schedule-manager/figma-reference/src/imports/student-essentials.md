Create a Student Essentials section inside the student dashboard. When the student clicks Student Essentials, it should open a clean panel that displays four interactive columns (cards) representing key student tools.

This task is focused on UI layout and interaction design only, not full backend functionality yet.

Section Header

At the top of the page display:

Student Essentials

Subtitle:

Quick tools to manage your academic life.

Add spacing so the header sits clearly above the cards.

Layout

Create a 4-column grid layout for the tools.

Desktop layout:

Schedule Manager | Attendance | Email Integration | Suggestions

Tablet layout:

2 × 2 grid

Mobile layout:

stack cards vertically

Each tool should appear as a large interactive card.

Card Design

Each card must contain:

• Icon at the top
• Title
• Short description
• Clickable area
• Hover animation

Card style:

rounded corners

soft shadow

subtle gradient or soft background

comfortable padding

balanced spacing between cards

Column 1 — Schedule Manager

Icon: calendar icon

Title:
Schedule Manager

Description:
Manage your classes and daily academic schedule.

Click behavior:
Opens the Schedule Manager module/page.

Column 2 — Attendance

Icon: checkmark or checklist icon

Title:
Attendance

Description:
Track your attendance across all courses.

Click behavior:
Opens the Attendance module/page.

Column 3 — Email Integration

Icon: mail or envelope icon

Title:
Email Integration

Description:
Connect your school email to receive academic updates.

Click behavior:
Opens the Email Integration module/page.

Column 4 — Suggestions

Icon: lightbulb or AI icon

Title:
Suggestions

Description:
Receive smart academic tips and recommendations.

Click behavior:
Opens the Suggestions module/page.

Animations

Add smooth, modern animations to improve the user experience.

1. Section Opening Animation

When the student clicks Student Essentials, the panel should appear with a smooth animation.

Animation type:

Fade in + slight upward slide.

Duration:

300–400ms.

Effect:

The entire section transitions smoothly instead of appearing instantly.

2. Card Hover Animation

When the user hovers over any card:

the card lifts slightly upward (5–8px)

shadow becomes slightly stronger

border or gradient subtly highlights

Duration:

200ms.

Effect:

Cards feel interactive and responsive.

3. Icon Micro Animations

Each card icon should animate slightly on hover.

Examples:

Schedule Manager → calendar icon slightly tilts or bounces
Attendance → checkmark pops or pulses
Email Integration → envelope opens slightly
Suggestions → lightbulb glows or softly pulses

Duration:

150–250ms.

Effect:

Adds personality without distracting the user.

4. Card Click Animation

When a card is clicked:

Card slightly scales down

Then opens the module page

Animation:

Scale: 1 → 0.97 → 1

Duration:

120ms.

After the click animation, the new module page slides in from the right.

5. Card Load Animation (Staggered Reveal)

When the Student Essentials section loads, the cards should appear one after another.

Order:

Schedule Manager

Attendance

Email Integration

Suggestions

Delay between cards:

80–100ms.

Effect:

Creates a smooth dashboard reveal instead of showing everything instantly.

6. Background Mesh Animation

If the dashboard uses a mesh gradient background, add subtle motion.

Animation:

Very slow gradient shifting.

Duration:

10–20 second loop.

Effect:

Keeps the interface visually alive without being distracting.

Design Goal

The Student Essentials section should feel like a clean academic control center where students can quickly access important tools.

The design should feel:

modern

smooth

simple

premium

intuitive for students

Animations should be subtle and fast, improving usability without slowing down the interface
