Design a modern web platform called AkadVerse, an AI-powered educational ecosystem, with three distinct user portals: Student, Faculty, and Admin. The design should reflect the following detailed specifications:

1️⃣ Student Portal (Primary Focus – Engaging, Premium UX)

Overall Style:

Apple-style simplicity, subtle glassmorphism on cards and panels

Slight inspiration from Airbnb: clean, airy spacing, friendly icons

Light pastel accents, rounded corners, soft shadows

Focused on visual engagement to capture student attention

Landing Page / Workspace Selector (Student Home)

Top bar: Search, Notifications, Profile

Back navigation: “← Back to Workspaces”

3 equal cards for workspace selection:

Productivity Layer – “AI-powered workspace for research, documents, and productivity tools” (Icon: ⚡)

Main Menu – “Campus tools, marketplace, and student essentials” (Icon: ☰)

E-Learning – “Access courses, learning materials, and academic progress” (Icon: 📚)

Cards include: icon, title, short description, hover lift animation

Non-clickable for MVP

Productivity Layer Page (3 Tools – MVP Focus)

Top bar & back navigation consistent

Grid layout with 3 tools:

AI Studio – Featured card (larger), “AI chat, research assistant, note summarizer, study planner” (Icon: 🤖)

Docs – “Collaborative documents for assignments and notes” (Icon: 📄)

Drive – “Upload, organize, and manage research and lecture files” (Icon: 📁)

Optional Recent Work section under tools: recent docs, AI summaries, uploaded files

Hover animations: subtle lift or shadow

Layout emphasizes AI Studio as primary tool

Main Menu Page (Student Life Hub – MVP)

3 equal cards (non-clickable):

Student Dashboard – “Announcements, quick academic overview, campus updates” (Icon: 🏠)

Marketplace – “Business Market, Skills Market” (Icon: 🛒)

Student Essentials – “Schedule Manager, Attendance, Email Integration, Suggestions” (Icon: 🧰)

Grid layout, hover highlight only

Top bar + back navigation consistent

E-Learning Page (Learning Hub)

3 equal cards (non-clickable) for MVP:

Learning Dashboard – overview of courses and progress

My Learning – student courses and modules

Learning Resources – lecture materials, PDFs, videos

Cards include: icon, title, short description

Top bar + back navigation consistent

Hover animation: subtle lift

Student Portal Animations / Interactions

Card hover: lift + subtle shadow

Featured AI Studio card slightly larger than others

Smooth fade-ins when page loads

Micro-interactions for tool icons (slight scaling on hover)

Navigation between pages: breadcrumb / back button transitions

2️⃣ Faculty Portal (Simplified, Functional)

Overall Style:

Neutral color palette: soft grays, muted blues

Minimal glassmorphism, almost none

Focused on clarity and ease-of-use for older users

Simple rectangular or slightly rounded cards, minimal shadows

Faculty Workspace Selector (Faculty Home)

Top bar: Search, Notifications, Profile

3 equal cards (non-clickable) for MVP:

Teaching Tools – “AI tools, Docs, Sheets, Drive for faculty” (Icon: ⚡)

Faculty Dashboard – “Overview of students, classes, announcements” (Icon: 🏠)

Courses & Resources – “Manage course content, teaching materials” (Icon: 📚)

Teaching Tools / Dashboard / Courses Pages

Grid or simple panel layout (no flashy card grids)

Minimal hover animations: only highlight on hover

Top bar consistent

Data displayed in tables, lists, or panels (student progress, assignments, schedules)

Typography: clear, legible sans-serif, slightly larger

Faculty Portal UX Notes

Focus on efficiency, readability, and quick navigation

No decorative animations or glass effects

Cards and sections should be straightforward and functional

3️⃣ Admin Portal (Functional, Direct)

Overall Style:

Very clean and neutral: muted grays, subtle blue accents

Minimalist UI: focus on institutional management

Minimal hover effects (row or card highlight only)

Admin Workspace Selector (Admin Home)

Top bar: Search, Notifications, Profile

3 equal cards (non-clickable) for MVP:

Admin Dashboard – “Overview of students, faculty, and campus KPIs” (Icon: 🏠)

Marketplace – “Business Market & Skills Market activity overview” (Icon: 🛒)

Smart Admin System – Coming Soon, includes: Institutional Intelligence, KPIs (Icon: ⚡)

Admin Dashboard Page

Top bar + back navigation consistent

Sections (all cards/panels rectangular, functional):

Communication Infrastructure → Coming Soon (Peer Messaging / Groups)

Marketplace → Business Market / Skills Market

Opportunity Hub → Coming Soon (Scholarships / Internships)

Smart Admin System → Coming Soon (Institutional Intelligence, KPIs)

Layout: tables, panels, lists for metrics and overview

Hover animations: minimal, highlight row or card only

Typography: highly legible, slightly larger for accessibility

Admin Portal UX Notes

Prioritize clarity, simplicity, and quick access to key institutional metrics

Non-MVP sections clearly labeled “Coming Soon”

Functional design ensures ease-of-use for less tech-savvy users
