Page Structure

Create an Attendance Dashboard with the following sections.

1. Attendance Overview (Top Section)

At the top of the page show a summary attendance card with:

Overall Attendance Percentage

Total Classes Attended

Total Classes Missed

Attendance Status Indicator

Example data:

Overall Attendance: 86%
Classes Attended: 38
Classes Missed: 6

Status indicator examples:

Green — Good Standing (Above 75%)
Yellow — Warning Zone
Red — Critical / Below Requirement

Also show a message:

“Students must maintain at least 75% attendance to remain eligible for examinations.”

2. Course Attendance Table

Below the overview, display attendance per course.

Use realistic Nigerian university course codes such as:

CSC 211 – Data Structures

MTH 213 – Engineering Mathematics

GST 211 – Nigerian Peoples and Culture

EEE 212 – Circuit Theory

CSC 214 – Computer Architecture

Show the following columns:

Course
Classes Held
Attended
Missed
Attendance %

Example row:

CSC 211 – Data Structures | 18 | 16 | 2 | 89%

Include visual progress bars representing attendance percentages.

Courses below 75% should display a warning indicator.

3. Recent Attendance Activity

Create a section showing the latest attendance records.

Example entries:

Mar 10 — CSC 211 Data Structures — Present
Mar 9 — MTH 213 Engineering Mathematics — Present
Mar 7 — EEE 212 Circuit Theory — Absent
Mar 6 — GST 211 Nigerian Peoples & Culture — Present

Use indicators:

Green — Present
Red — Absent
Yellow — Late

4. Attendance Warning System

If any course attendance drops below 75%, display a warning alert such as:

“Your attendance in EEE 212 – Circuit Theory is below the required threshold.”

The warning should appear as a notification card.

5. Optional Attendance Insights

Add small automated insights such as:

“You have missed 3 classes this month.”

“Your highest attendance is in Computer Architecture (92%).”

“Attend the next 2 classes in Circuit Theory to stay above 75%.”

Animations

Use smooth modern UI animations.

Page Entrance

When the Attendance page opens:

Slide in from the right

Fade in
Duration: 250–300ms

Attendance Overview

Animate the attendance percentage:

Example:

0% → 86%

Use a count-up number animation and progress fill.

Duration: 700–800ms

Course Progress Bars

Progress bars should animate from 0% to their final value when the page loads.

Duration: 600–700ms

Hover Effects (Course Rows)

When hovering over a course row:

Slight lift effect (about 4px)

Soft shadow

Highlight background

Duration: 150–200ms

Optional tooltip example:

“Attend the next 2 classes to stay above 75%.”

Recent Attendance Activity

Attendance entries should fade in sequentially when the page loads.

Each item appears with a slight delay to create a smooth list reveal effect.

Warning Alerts

If attendance drops below the required level:

The warning card should slide down and fade in.

Duration: 250ms

Design Goal

The page should look like a real university attendance management dashboard, with:

Clear data visualization

Realistic course information

Progress indicators

Smart warnings

Smooth UI animations

The design should feel modern, professional, and interactive, suitable for a student productivity platform.
