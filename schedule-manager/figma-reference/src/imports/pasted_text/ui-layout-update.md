# AkadVerse — Final UI Layout & Navigation Update

Edit the existing **AkadVerse** web app interface based on the changes below.

**IMPORTANT:** Do not redesign AkadVerse from scratch. Preserve the existing visual identity, color palette, typography, icons, components, card styling, borders, shadows, animations, transitions, spacing system, and overall premium academic-tech aesthetic. The goal is to **reorganize and improve the existing interface**, not replace it.

---

## 1. Opening Page — Main Feature Layout

The AkadVerse opening page should contain exactly **7 primary feature cards**:

1. AI Studio
2. Main Menu
3. Productivity Layer
4. E-Learning
5. Communication Infrastructure
6. Marketplace
7. Opportunity Hub

Do **not** force these into a conventional 3×3 grid. Use an intentional asymmetrical layout that gives the most important features appropriate visual weight.

### Recommended arrangement

**Top section:**

* **AI Studio** — make this the visually dominant/hero card.
* **Main Menu** — positioned beside AI Studio.
* **Productivity Layer** — positioned alongside the core feature area.

**Middle section:**

* **Communication Infrastructure** — a wider card.
* **E-Learning**
* **Marketplace**

**Bottom section:**

* **Opportunity Hub** — a wide horizontal card spanning approximately the combined width of the E-Learning and Marketplace cards.

The layout should feel balanced and intentional rather than like seven cards placed into empty spaces.

---

## 2. AI Studio

Make **AI Studio** the most visually prominent feature because it is one of AkadVerse's key differentiators.

Keep its existing design language, but allow it to occupy a larger visual area than the standard cards.

It should immediately communicate that AI is a major part of the AkadVerse ecosystem.

---

## 3. Opportunity Hub

Make **Opportunity Hub** a wide horizontal feature card.

Its width should approximately span the combined width of the **E-Learning + Marketplace** cards above it.

The card should contain:

**Title:**
Opportunity Hub

**Supporting text:**
A short description communicating that students can discover opportunities beyond campus, such as internships, scholarships, competitions, programs, fellowships, and other academic/career opportunities.

### Small animated logo element

Place a **small animated logo/icon directly beside the Opportunity Hub content**, preferably toward the right side of the card.

The logo must remain **small and secondary**. It should never overpower the Opportunity Hub title or description.

The small visual should smoothly transition between different logos representing organizations that provide opportunities, such as:

* Universities
* Companies
* Organizations
* Startups
* Scholarship providers
* Academic institutions
* Student programs

The animation should cycle smoothly:

**Logo 1 → Logo 2 → Logo 3 → Logo 4 → Logo 5 → repeat**

Use a subtle **fade, scale, or crossfade transition**.

Keep the animation elegant and minimal so it feels like part of the AkadVerse interface rather than a distracting advertisement.

If the logos have different shapes or proportions, place them inside a consistent small rounded container so the visual remains stable during transitions.

---

# 4. Main Menu Changes

Remove the following from the **Main Menu/navigation**:

* Communication Infrastructure
* Marketplace
* Opportunity Hub

These three features should now exist as primary feature cards in the opening-page feature area described above.

The Main Menu should therefore become cleaner and less crowded.

Do not remove any unrelated Main Menu functionality.

---

# 5. Feature Card Grid

The feature area containing the major AkadVerse services should accommodate the additional features cleanly.

Where cards are displayed in a standard grid, use **3 cards per row** where appropriate.

Resize the cards proportionally so that three cards fit comfortably in each row.

Maintain:

* Equal spacing
* Consistent alignment
* Consistent card proportions
* Existing border radius
* Existing shadows
* Existing borders
* Existing hover states
* Existing transitions
* Existing animations

Do not make the cards cramped.

---

# 6. Remove Student Essentials From Navigation

Completely remove the **Student Essentials** section from the menu/navigation.

Remove these features from that section:

* Schedule Manager
* Attendance
* Email Integration
* Suggestions

These features should no longer appear under Student Essentials in the navigation.

---

# 7. Move Student Essentials Features to Student Dashboard

Move the four features directly into the **Student Dashboard**:

* Schedule Manager
* Attendance
* Email Integration
* Suggestions

Place them **directly underneath the Recent Messages section**.

---

# 8. Student Dashboard — 2×2 Layout

Arrange the four features in a clean **2×2 grid**.

### Top row

**Schedule Manager | Attendance**

### Bottom row

**Email Integration | Suggestions**

Use wide, comfortable cards with enough padding and spacing.

The cards should have a **decently long horizontal border/container** so they do not look compressed.

Maintain the existing AkadVerse card styling.

---

# 9. Animation & Interaction Consistency

Every newly moved or resized element must use the **same animation and interaction language already present throughout AkadVerse**.

Preserve and apply:

* Entrance animations
* Hover animations
* Smooth transitions
* Border animations
* Card movement
* Micro-interactions
* Existing loading/transition behavior

Do not introduce a completely different animation style.

The newly positioned elements should feel as though they were originally designed as part of AkadVerse.

---

# 10. Responsive Behavior

Ensure the redesigned layout remains responsive.

On smaller screens:

* Cards should stack naturally.
* No text should overlap.
* No card should become excessively narrow.
* Opportunity Hub should remain visually prominent.
* The animated logo should remain small and properly aligned.
* The Student Dashboard 2×2 grid should collapse appropriately when necessary.

Do not sacrifice usability for the desktop layout.

---

# Final Design Goal

The final AkadVerse experience should feel like a **modern academic ecosystem and productivity platform**, not a traditional university portal.

The opening page should clearly communicate the platform's ecosystem:

**AI → Navigation → Productivity → Learning → Communication → Marketplace → Opportunities**

The navigation should be cleaner, the Student Dashboard should contain more useful information directly within the main workspace, and **Opportunity Hub should provide a distinctive visual moment with its small rotating organization logos.**

Do not change unrelated functionality or redesign existing components unnecessarily. Only make the structural, positioning, sizing, and navigation changes described above while preserving the established AkadVerse design system.
