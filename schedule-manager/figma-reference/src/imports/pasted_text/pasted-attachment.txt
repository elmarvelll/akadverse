Edit and enhance the AI Studio section of AkadVerse to create a modern, highly interactive AI workspace for both students and faculty.

The AI Studio should function as a central AI command center for learning, productivity, and operations.

The system should contain two pages:

AI Studio Dashboard (AI tool selection page)

AI Tool Interface (universal AI interaction interface)

Maintain visual consistency with the rest of the AkadVerse UI.

Apply these UX principles:

Von Restorff Effect (highlight primary actions)

Miller’s Law (limit visible choices per section)

Proximity Law (group related AI tools)

Hick’s Law (avoid overwhelming the user)

Jakob’s Law (follow familiar AI interface patterns)

The experience should feel similar to modern AI tools like ChatGPT, Notion AI, and Perplexity AI.

PAGE 1 — AI STUDIO DASHBOARD

This page acts as the AI command center.

Display all AI tools using grouped sections and interactive cards.

Layout:

Scrollable vertical page with sections.

Each section contains AI cards arranged in a responsive grid.

Card size:

280–320px width

Card contents:

• icon
• AI tool name
• short description
• hover animation
• click interaction

PAGE 2 — UNIVERSAL AI TOOL INTERFACE

When any AI card is clicked, open a unified AI interface.

This interface must remain the same for all tools.

Layout

Top area:

AI tool name
short description

Example:

Note Creator
Create structured notes from any content.

Center area:

conversation/chat panel.

Messages appear in conversation bubbles.

AI responses appear with smooth fade-in.

Bottom area:

input interaction panel.

Users can interact with the AI in three ways.

Input Methods
Upload File

Supported formats:

PDF
DOCX
Slides
Images
Notes

Upload animation:

file card appears
progress bar fills smoothly.

Voice Input

Users can record a voice note.

Animation:

pulsing microphone
soundwave visualization.

Text Prompt

Typing field similar to modern AI chat tools.

Placeholder example:

"Upload notes or ask the AI to generate study material."

Typing animation:

cursor glow
send button pulse.

Smart Action Suggestions

When files are uploaded, show quick AI actions.

Example:

Generate Quiz
Summarize Notes
Create Slides
Explain Concepts

Each action appears as clickable suggestion chips.

Hover animation:

chip lifts slightly.

AI Thinking Animation

While the AI processes input:

Show animated typing dots.

Optional:

soft neural pulse animation.

Result Display

Results appear with smooth animations:

text fades in
generated content slides upward

Example outputs:

quiz questions
slides
summaries
practice questions.

Page Transitions

Transitions between AI tools and interface:

slide + fade.

Duration:

250–300ms.
