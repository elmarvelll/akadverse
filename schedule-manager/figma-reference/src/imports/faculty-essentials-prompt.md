Final Prompt — Faculty Essentials Tools Behavior

Create the Faculty Essentials page for lecturers on an academic platform used by Covenant University.

This page should contain the same core productivity tools available to students but adapted for faculty use.

Display four main tool cards.

[ Schedule Manager ]   [ Attendance ]

[ Email Integration ]  [ Suggestions ]

Each card should contain:

Tool icon

Tool name

Short description

Hover animation

Click interaction that opens the tool workspace

Cards should have rounded corners, subtle shadows, and smooth hover animations.

Hover behavior:

Card lifts slightly (5–8px)

Shadow becomes stronger

Duration: 200ms

Click behavior:

Card compresses slightly

Page opens with smooth transition

Duration: 120ms

1. Schedule Manager (Shared with Students)

When the Schedule Manager card is clicked, open a schedule dashboard showing academic schedules.

The system should be the same system used by students, but lecturers can manage classes.

Features include:

View weekly teaching schedule

See upcoming lectures

Add or adjust lecture sessions

Schedule extra classes

View classroom or online meeting links

Example schedule entry:

CSC 211 – Data Structures
Monday 09:00 – 10:30
Engineering Hall 302

EEE 214 – Circuit Analysis
Wednesday 13:00 – 14:30
Room 204

Students and lecturers both see this schedule, but faculty can edit and manage it.

2. Attendance (Faculty Controlled)

When Attendance is clicked, open the Attendance Management Dashboard.

Attendance for students is recorded and managed by faculty from this interface.

Features should include:

Class Selection

Lecturers select the course session.

Example:

CSC 211 – Data Structures
Class Size: 82 students

Attendance Recording

Lecturers can mark students:

Present
Absent
Late

Example student entry:

Daniel Adeyemi — Present
Grace Okafor — Present
John Mensah — Absent

Attendance Summary

Display statistics such as:

Students Present: 74
Students Absent: 8
Attendance Rate: 90%

Attendance Alerts

Highlight students with low attendance percentages.

Example:

“5 students are below the 75% attendance requirement.”

Students should not control attendance, they only see their attendance records on the student side.

3. Email Integration (Shared System)

When Email Integration is clicked, open the academic email workspace.

This system should be identical to the student email system, allowing communication between students and faculty.

Features:

Inbox
Sent Mail
Drafts
Compose Email

Example messages:

From: Dr. Adewale
Subject: Assignment Feedback
Time: 2 hours ago

From: Department Admin
Subject: Faculty Meeting Reminder
Time: Yesterday

Faculty can send emails to:

Individual students

Entire course classes

Departments

4. Suggestions (Shared AI Tool)

When Suggestions is clicked, open an AI-powered recommendation panel.

This tool provides intelligent suggestions for lecturers.

Examples:

Students struggling academically

Students with low attendance

Suggested revision topics

Suggested assignment improvements

Example suggestion:

“6 students in CSC 211 scored below 50% in the last quiz.”

“Average attendance dropped by 8% this week.”

This helps lecturers identify issues and improve teaching effectiveness.

Receive AI-driven insights
